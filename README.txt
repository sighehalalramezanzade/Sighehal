راهنمای انتشار سایت
1) فایل ZIP را استخراج کنید.
2) فایل‌های index.html، style.css، script.js و banner.png را همگی مستقیماً در ریشه مخزن GitHub آپلود کنید؛ پوشه نسازید.
3) در GitHub وارد Settings > Pages شوید.
4) گزینه Deploy from a branch را انتخاب کنید، Branch را روی main و Folder را روی /(root) بگذارید و Save کنید.
5) پس از فعال شدن Pages، آدرس سایت شما به شکل https://USERNAME.github.io/REPOSITORY/ خواهد بود.

نکته سئو:
- هیچ فایلی نمی‌تواند رتبه اول گوگل را تضمین کند. برای دیده‌شدن بهتر، دامنه اختصاصی، محتوای مفید و اصیل، لینک‌سازی طبیعی و ثبت سایت در Google Search Console لازم است.
- پس از انتشار، آدرس دقیق سایت را در Google Search Console ثبت و درخواست ایندکس صفحه اصلی را ارسال کنید.
- شماره تماس و لینک تلگرام در سایت درج شده‌اند.
- متن سایت عمداً از ادعای مجوز، ثبت رسمی یا تضمین نتیجه خودداری می‌کند؛ فقط در صورت داشتن مجوز معتبر، اطلاعات دقیق و قابل اثبات آن را اضافه کنید.
